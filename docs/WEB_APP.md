# Aplicação web

O frontend fica em `frontend/` e o servidor Bun fica em `backend/`.

Para iniciar:

```bash
bun install
bun run server
```

Depois, abra `http://localhost:3001`. Configure pelo menos uma chave Blockfrost
na aba **Rede & logs**. Preview e Preprod são independentes: uma rede sem chave
fica bloqueada até ser configurada.
